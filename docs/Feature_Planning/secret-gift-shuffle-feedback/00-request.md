# Secret Gift: admin feedback after shuffle — request

*Written by the user. Free form, may be three lines. Everything below is
optional prompting, not a form to fill.*

## What I want

In the Secret Gift event (Calendar module), performing the shuffle does not
start the event. The admin of the event should get clear feedback about where
things stand after shuffling.

## Why

The admin of the event has no feedback saying the event started, and does not
see the shuffling.

## Constraints or ideas I already have

Two options, to be decided:

- Show the shuffling to the admin, stating that the event is not started yet,
  so that they can see the shuffling; or
- Ask the admin to start the event once the shuffling is done.
