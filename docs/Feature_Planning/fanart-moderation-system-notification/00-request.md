# Fanart moderation notification as system notification — request

*Written by the user. Free form, may be three lines. Everything below is optional prompting, not a form to fill.*

## What I want

When a fanart is moderated, the notification should be a system notification. Right now it shows the user (the moderator) as the sender instead.

## Why

The fanartist whose fanart was moderated can see who moderated it, and so knows who to complain to. A system notification would not expose that.
