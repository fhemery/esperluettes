# Quotes - handle private stories

## What I want

Quotes should work on private stories (they currently don't). Users should be able to view private stories quotes, and authors should be notified, but other members should not be able to view them.
## Why

Quotes on private stories should be doable, but it is critical not to leak those quote to outside people. 
## Scope

Quotes domain
## Constraints

- Ensure as well that community quotes are not visible from non confirmed users. 
-  If possible and not performance breaking, make private quotes visible by people who also can view the story (i.e. other beta readers of this story)
